# 抽題規格 EXTRACT.md — 所有抽題 agent 共用(派工提示只需指到本檔,毋須重述)

派工提示範本(短):
> 讀 `exam/img/<id>/` 的 `text.txt`(題目文字層)與 `answer.txt`(答案);依 `exam/tools/EXTRACT.md` 抽成 `q_<id>.json` 寫到 <scratch>。無 text.txt 的掃描卷才讀 `q*.jpg`;答案是圖(route=text+visionAns)才讀 `a*.jpg`。一次讀完即抽,勿反覆重讀整頁、勿寫完再逐題回讀驗證;僅某字形/圖不清時才裁切放大。回報:題數、各 section 數、待確認題。

## 輸出:q_<id>.json = 題物件陣列,每題欄位
- `n`:題號(字串)。
- `section`:選擇 / 填充 / 計算 / 閱讀測驗 / 非選擇 / 聽力 / 是非。
- `stem`:題幹。數學正規化:`x^2`、`√`、分數用 `a/b`、`×÷≤≥∠°`;勿把散落圖形標籤混進題幹。
- `options`:選項陣列(無則 `[]`);選擇題純文字,勿含 (A)(B) 前綴。
- `answer`:標準答案(選擇填 A/B/C/D;非選填參考答案或留空)。
- `needsFigure`:需看圖才可作答 → true;`figureRef`:該圖所在頁圖路徑(如 `exam/img/<id>/q2.jpg`)。
- `needsAudio`:英聽題 → true(無音檔,出卷會自動排除,待 TTS)。

## 規則
- **答案務必對照 answer.txt / 答案頁核對**;可計算的題(數學/理化)再獨立重算驗證。
- 官方答案偶有誤植:以答案頁為準並在 stem 末註記;少數依物理/數學重算改判者,註明理由。
- 答案 PDF 有時是試卷副本、答案在末頁答案表(a*.jpg 與 q*.jpg 相同):讀末頁答案表即可。
- 國文注音**以教育部辭典為準**,勿用大陸讀音;與原卷牴觸時採教育部並註記原卷值。
- 版權:題幹照抄原卷即可(使用者自有教材),但**勿在對話回覆裡貼題目內容**,回報只給統計(題數/section/待確認)。
- 掃描卷(無 text.txt)照舊讀 `q*.jpg` 逐題抽;文字卷不必開圖。
